# yearning.

A physical-feeling beginning, on paper. M0/M1 visual study for a voice-first personal website creation experience.

```sh
npm ci
npm run demo
```

Node 24. No paid API keys, database, microphone, or audio required. Begin, then choose **Try a name** to exercise the explicitly mocked arbitrary-name reveal. This does not yet provide live voice, drawing, or website generation.

See [implementation status](docs/IMPLEMENTATION_STATUS.md), [runbook](docs/RUNBOOK.md), [art direction](docs/ART_DIRECTION.md), [architecture](docs/ARCHITECTURE.md), [asset requests](ASSET_REQUESTS.md), and the [complete specification](docs/YEARning_CODEX_SPEC.md).
